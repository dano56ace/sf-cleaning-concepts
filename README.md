# South Florida Cleaning Concepts — Website Rebuild

Modern, blazingly fast rebuild of the South Florida Cleaning Concepts website built with Vite 6 and Multi-Page Vanilla HTML5, modern CSS3, and ESM JavaScript.

## Architecture & Features
- **Zero Runtime Framework Overhead**: Pure semantic HTML5 + CSS custom properties + vanilla ESM JavaScript.
- **Fast Performance**: Sub-millisecond load times, zero-CLS responsive video hero and media players.
- **Multi-Page Application (MPA)**: 28 canonical pages (6 core, 11 service landing pages, 11 educational blog articles).
- **Comprehensive Media Pipeline**: Ingested and verified local library of 431 assets including 4 MP4 video assets, 1 MP3 audio track, and full brand graphics.
- **Deployment Ready**: Optimized for Netlify with strict security headers (CSP, HSTS, X-Content-Type-Options) and immutable static caching.

## Development Scripts

```bash
# Install dependencies
pnpm install

# Start local dev server
npm run dev

# Run production build (compiles to dist/)
npm run build

# Preview production build
npm run preview
```
